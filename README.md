## 🌟 Key Highlights & Engineering Features

- **🪐 4D Cyber-Hologram Avatar Experience**:
  - Dual counter-rotating neon orbital rings with orbiting satellite beacons.
  - 4D spatial breathing float and parallax floating tech badges (*Full Stack* & *GenAI/ML*).
- **⚡ 0.0000% Lag Performance (120/144 FPS)**:
  - **Zero CPU Animation Overhead:** Pure CSS GPU transforms (`translate3d`, `rotate3d`, `transform: translateZ(0)`).
  - **Zero Tap Delay:** Instant touch response (`touch-action: manipulation`) across iOS and Android devices.
  - **Content-Visibility Optimization:** Off-screen sections skip initial paint passes for instant load and buttery-smooth scrolling.
- **🎨 "Cyber-Aurora Obsidian" Design System**:
  - Deep space void backgrounds (`#030712`) with ambient radial neon light meshes.
  - Neon Hyper-Violet (`#8B5CF6`), Electric Cyan (`#22D3EE`), and Hot Pink (`#EC4899`) gradients.
  - Glassmorphic cards with glowing multi-accent hover borders.
- **📱 100% Mobile & Touch Optimized**:
  - Precision touch targets ($\ge 44\text{px}$) adhering to Apple Human Interface Guidelines.
  - Responsive layout scaling effortlessly from small smartphones (320px) to ultra-wide 4K monitors.
- **📍 Real GitHub Experience & Projects**:
  - Highlights real engineering projects (Face Recognition Attendance, GenAI Assistant, CNN Classification, Customer Analytics).

## 🚀 Getting Started

To run this portfolio locally on your machine:

### 1. Prerequisites
Ensure you have [Node.js](https://nodejs.org/) (v18 or higher) and [Git](https://git-scm.com/) installed.

### 2. Clone the Repository
```bash
git clone https://github.com/SuprabhSharma/Web_Portfolio.git
cd Web_Portfolio
```

### 3. Install Dependencies
```bash
npm install
```

### 4. Start Development Server
```bash
npm run dev
```
Open your browser and navigate to `http://localhost:5173`.

### 5. Build for Production
```bash
npm run build
```
